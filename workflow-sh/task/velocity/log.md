# velocity / log

> 마일스톤마다 실측 속도를 1행으로 누적한다.
> milestone.md의 "잡힌 양" 추정을 실측치 기반으로 교체하기 위한 데이터 소스.

---

## 사용법

- **작성 시점**: D6 `review.md` 작성 직후 바로 1행 추가 (5분 이내)
- **활용 시점**: 다음 milestone 잡힌 양 결정 전 이 파일을 먼저 읽기
- **기준**: 계획 대비 실제 머지 수가 1차 속도 지표. 막힘 원인을 짧게 기록해야 다음에 활용됨

---

## 컬럼 설명

| 컬럼 | 설명 |
| --- | --- |
| 버전 | milestone 버전 (SemVer) |
| 기간 | D1 ~ D6 날짜 |
| 계획 Story | milestone.md의 Tier 1 + Tier 2 합계 |
| 실제 머지 | 실제로 머지된 Story 수 |
| 달성률 | 실제 / 계획 × 100 |
| 최대 카테고리 비중 | 코드 / 인프라 / 관측성 중 가장 높은 비중 |
| 주요 막힘 | 가장 오래 걸린 단일 원인 + 소요 시간 |
| 속도 보정 제안 | 다음 milestone 잡힌 양 조정 방향 |

## 속도 구간 해석 (3버전 이상 누적 후 유효)

| 달성률 | 해석 | 다음 milestone 조정 |
| --- | --- | --- |
| ≥ 90% | 정상 속도 | 동등하거나 +10% 잡기 가능 |
| 70 ~ 89% | 약간 과적 | -10% 줄이거나 Tier 2 완충 늘리기 |
| 50 ~ 69% | 과적 or 큰 막힘 | Tier 1만 잡고 Tier 2 없음 |
| < 50% | 구조적 문제 | `drift/patterns.md` 원인 분류 필수 |
