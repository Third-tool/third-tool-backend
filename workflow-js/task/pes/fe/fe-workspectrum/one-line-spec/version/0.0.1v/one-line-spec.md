# [One-line-spec] FE 양식 정의

> FE 작업 양 스펙트럼 최소 단위. 한 문장으로 충분한 요구사항 + 1~3개의 완료 신호.
> 백엔드 동일 양식의 FE 버전이며 트리거·골격은 같다.

---

## 사용 시점 (트리거)

다음 조건을 **모두** 만족할 때 본 양식을 쓴다.

- [ ] 추정 작업 시간 **1시간 이내**
- [ ] 영향 받는 파일 **1개** (단일 컴포넌트 / 단일 hook / 단일 endpoint 모듈 / 단일 Zod 스키마 / 단일 라우트 항목)
- [ ] 외부 시스템·인프라 변경 **0건** (`vite.config.ts`/`tsconfig.json`/CI 설정 미포함)
- [ ] 검증 가능한 완료 신호가 **1~3개**로 떨어짐 (Vitest 1건, `npm run typecheck` 통과, 브라우저 수동 확인 1건 등)
- [ ] 도메인 규칙·Zod 스키마 변경 **없음** (단순 문구·className·복사값 갱신)

**졸업 신호 → feature-story로**:
- 영향 파일이 2개 이상으로 늘어남 (예: 컴포넌트 + hook + endpoint)
- 단위 테스트가 새로 필요 (해피/엣지/예외 매트릭스가 떠오름)
- 한 줄로 요구사항이 표현되지 않음 (조건 분기·에러 처리가 끼어듦)

---

## 양식 골격

```
# [Spec] {한 줄 요구사항}

## 타깃
- {파일 1~2개 정확한 경로 — src/features/... 또는 src/lib/... 또는 src/components/...}

## 완료 신호
- [ ] {1번 신호}
- [ ] {2번 신호 — 선택}
- [ ] {3번 신호 — 선택}

## 비범위
- {범위 밖 1줄}

## 관련 (선택)
- ADR/Story/PR 링크 또는 N/A
```

### 섹션 가이드

| 섹션 | 채울 것 |
| --- | --- |
| **제목** | 한 문장. 동사로 시작. 예: "LandingPage CTA 카피를 '시작' → '무료로 시작'으로 변경" |
| **타깃** | 절대 경로 또는 src 상대 경로. 추정 표현(`*Page.tsx` 같은 와일드카드) 금지 |
| **완료 신호** | 실행 가능한 검증. "`npm run typecheck` 통과" / "이 문자열이 화면에 노출" / "이 줄이 사라짐" 같은 **사실** |
| **비범위** | 1줄. "다른 페이지 동일 카피 일괄 변경 X", "Tailwind 클래스 재구성 동반 X" 같은 범위 차단 |
| **관련** | 추적 가치 있을 때만. 없으면 항목 자체 생략 |

---

## 예시

```
# [Spec] LandingPage CTA 카피 '시작' → '무료로 시작'

## 타깃
- src/features/landing/LandingPage.tsx

## 완료 신호
- [ ] LandingPage 안의 "시작" 텍스트 1건이 "무료로 시작"으로 변경
- [ ] npm run typecheck 통과
- [ ] npm run lint 통과

## 비범위
- 다른 페이지 동일 카피 일괄 변경은 별 작업
- 버튼 variant·간격 재조정 동반 X

## 관련
- N/A
```
